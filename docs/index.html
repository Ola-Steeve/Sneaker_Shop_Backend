🏃‍♂️ Sneaker Shop Backend API

RESTful API for managing sneaker products, users, and orders

🟢 API Status: Live

📖 API Overview

This backend API provides comprehensive endpoints for a sneaker e-commerce platform. Built with Node.js, Express.js, and MongoDB.

🚀 Base URL

https://your-api-domain.com/api/v1

🔐 Authentication

The API uses JWT tokens for authentication. Include the token in the Authorization header:

Authorization: Bearer your_jwt_token

📚 API Endpoints

🔑 Authentication Routes

POST /api/v1/auth/register

Register a new user account

POST /api/v1/auth/login

Login with existing credentials

GET /api/v1/auth/logout

Logout the current user

👟 Product Routes

GET /api/v1/product

Get all products

GET /api/v1/product/:id

Get a specific product by ID

POST /api/v1/product

Create a new product (Admin only)

PATCH /api/v1/product

Update an existing product (Admin only)

DELETE /api/v1/product/:id

Delete a product (Admin only)

👤 User Routes

GET /api/v1/user

Get user profile information

🛒 Order Routes

POST /api/v1/order

Create a new order

GET /api/v1/order

Get all orders

🛠️ Technology Stack

  • Runtime: Node.js
  • Framework: Express.js
  • Database: MongoDB with Mongoose
  • Authentication: JWT (JSON Web Tokens)
  • Security: Helmet, XSS protection, CORS
  • File Upload: Multer
  • Logging: Morgan

🔧 Development

Getting Started

# Clone the repository
git clone https://github.com/Ola-Steeve/Sneaker_Shop_Backend.git

# Install dependencies
npm install --legacy-peer-deps

# Set up environment variables
cp .env.example .env

# Start development server
npm run dev

# Start production server
npm start

Environment Variables

  • MONGO_URL - MongoDB connection string
  • JWT_SECRET - Secret key for JWT tokens
  • PORT - Server port (default: 4500)
  • ALLOWED_URL - Allowed CORS origins
